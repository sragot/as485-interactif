Le tableau de bord

Un tableau de bord autonome (données embarquées, aucun serveur requis) qui couvre les usagers desservis et les listes d'attente en DI-TSA, les effectifs, ainsi que les dépenses par région, par centre d'activités et le soutien à domicile (SAD).

Les jeux de données

Toutes les données sont publiées en format long, UTF-8 (CSV + Parquet), harmonisées depuis les sources du MSSS. Elles sont disponibles dans le dépôt :
